# Embryo Security Watch

Embryo Security Watch is Embryo-Zero's fork of [wazuh](https://github.com/wazuh/wazuh) (365f96f, commit 365f96f). It does security monitoring and alerts for every machine.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
